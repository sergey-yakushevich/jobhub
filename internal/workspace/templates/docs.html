API

GET / POST /api/v1/jobs GET / PATCH /api/v1/jobs/{id} GET / POST /api/v1/jobs/{id}/events GET /api/v1/openapi.json GET /api/v1/stats?profile=sergey
Authentication 
Authorization: Bearer $JOBHUB_API_KEY
Content-Type: application/json

Key: .env.local. Bearer header required; browser sessions do not authorize the API.

Examples

Create job

POST /api/v1/jobs
{"source_key":"acme:backend","company":"Acme","title":"Backend Engineer"}

Log event

POST /api/v1/jobs/1/events
{"source_key":"email:42","kind":"message","summary":"Interview requested","actor":"Alex","channel":"email","direction":"inbound"}

Update job

PATCH /api/v1/jobs/1
If-Match: "3"
{"next_action":"Confirm interview","needs_you":true}
Write rules & filters
  • source_key: identical retries return 200; changed payloads return 409. New records return 201.
  • PATCH requires the current ETag in If-Match. Missing: 428; stale: 409. Events also advance the version.
  • Timeline is append-only. Optional event stage changes the job atomically. Logging never sends anything.
  • confirmed is the recorder's assertion. Only check events advance last_checked_at.
  • Job filters: profile, stage, remote, needs_you, q.
  • stage=active: applied, talking or interview. Stats are a full profile overview, independent of list filters. Daily counts cover 30 UTC days.
  • Lists return items and next_cursor. Continue with cursor and limit (1–100).
  • Clear numbers with null, strings with "", lists with []. Errors: {"error":{"code":"…","message":"…"}}.
